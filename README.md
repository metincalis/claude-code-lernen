# Claude Code lernen

Mein Lernprojekt, um Schritt für Schritt mit Claude Code zu arbeiten: Dateien anlegen, Code schreiben, mit Git versionieren und auf GitHub sichern.

## Aufbau

```
claude-code-lernen/
├── README.md          ← diese Datei: Überblick über das Projekt
├── CLAUDE.md          ← Regeln für Claude Code in diesem Repo
├── .gitignore         ← Dateien, die Git ignorieren soll (z. B. .DS_Store)
└── uebungen/          ← eine Datei pro Lektion
    └── lektion-1.html
```

## Übungen ansehen

1. Repo herunterladen oder klonen: `git clone https://github.com/metincalis/claude-code-lernen.git`
2. Im Ordner `uebungen/` eine `.html`-Datei per Doppelklick öffnen – sie startet im Browser.

Es braucht keine Installation und keinen Server.
